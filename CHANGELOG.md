# Changelog

All notable changes to Flashex are listed here, newest first.
Each version links to its release, where the dmg, its SHA-256 and the signed update manifest are attached.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/): **Added** for new features, **Changed** for changes to existing behaviour, **Fixed** for bug fixes, **Removed** for features that are gone, and **Security** for anything that affects your safety.
Versions follow [Semantic Versioning](https://semver.org/).

## [Unreleased]

## [0.2.14] - 2026-10-24

### Changed
- **Connecting to the Mac looks as it did:** the card in the middle over the blurred page, in a chat too (0.2.13 had a strip at the top there). What you sent as the connection went still goes once the Mac is back.

### Fixed
- **The phone connects when Flashex was opened from the Dock or after an update:** Flashex asked Tailscale's app for this Mac's tailnet address in a way it answers only in a terminal, so it never learned it, turned the phone away and showed no QR code ("Tailscale is off" on the phone, though it was on).
- **The phone connects once Tailscale is up:** when Flashex started before Tailscale and phone access was set again meanwhile (its preview turned on or off, say), it never learned this Mac's tailnet address and turned the phone away ("Tailscale is off" on the phone). It now keeps asking, and follows a new address too.
- **A notification opens its agent's chat** on the phone (its terminal when it has none), and Back goes to the agents, not to what was open before.
- **Phone access after an update:** it waits a moment for its port while the app before still holds it, instead of not starting.
- **An update no longer starts a second Flashex:** a keeper staying for terminals from before an earlier update became the new program as the app instead of as a keeper, so a second Flashex started with its own terminals and resumed the same Claude Code sessions again (0.2.12 and 0.2.13). It stays a keeper now, and a test of the app's own binary guards this before every release.

## [0.2.13] - 2026-10-24

### Changed
- **The Mac by its name:** System shows "MacBook Air (13-inch, M4, 2025)" and the like (on the phone too), its model identifier ("Mac16,12") beside it in the details.
- **Quitting asks with the program's name too:** a terminal whose shell has no Flashex integration is named with the program in its foreground ("api — npm"), not only by its tab.

### Added
- **Search every conversation from the phone:** the magnifier on Agents finds what you or an agent said in any conversation on the Mac; one that runs now opens its chat, an older one goes on in a new terminal in its folder.
- **Copy on the phone:** a reply has a copy button beside its speaker, and a block of code its own Copy.
- **The next agent waiting, one tap away:** a chat says when another agent waits for you, and takes you there.
- **A short buzz on the phone** when an agent starts waiting for you while the app is open (where the phone can vibrate).
- **Messages wait for the Mac:** in a chat you can go on writing while the Mac is away; what you send is kept on the phone ("Waiting for your Mac…") and sent once it is back. A strip at the top says it connects, the chat stays usable.
- **The Mac's sidebar shows a command in the background** as the agent at work, as the phone does.
- **Keep Mac Awake on the phone does what the Mac's does:** a duration of your own (Custom…: 90, 1h30, until 18:30), the display and screen lock while it is on (display on and no lock, screen saver as usual, or the display may sleep), and while it is on Turn display off, Lock the Mac and +1 hour.
- **An agent with a command running in the background stays at work** on the phone ("A command runs in the background", green), until Claude Code tells the command finished; before, it showed "Done · your turn" while it went on.
- **Shortcuts on the phone app's icon** (a long press): **Agents**, **New agent** (it asks in which project) and **Last chat**.
- **Claude Code's suggestion in the phone's chat:** the next message Claude Code offers in its prompt (taken with → on the Mac) shows over the message box; a tap puts it there to send or change.
- **The chat's details on the phone list the subagents:** those working (what each does, its tool now, for how long, whether it waits for you) and the last ones done (how long they took).
- **Gemini CLI connected:** Settings › AI agents › **Gemini CLI hooks** › Install puts Flashex's hooks in `~/.gemini/settings.json`; Gemini's state, its permission questions and finished turns then reach the sidebar, the Agents dashboard, notifications and the phone, as Codex's do.
- **Remove a worktree:** Git › Remove Worktree… (and **+ › Remove a worktree…** on the phone) lists the project's worktrees, such as a worktree agent's, and removes one after a question. Its branch goes too when it is merged, else it stays. A worktree with changes, or one a terminal is in, is never removed.
- **Told before the 5-hour limit runs out:** with Settings › Usage › notify on, Flashex also says when the limit runs out at this pace within 45 minutes and before it resets ("At this pace Claude's 5-hour limit runs out at 15:40 (in 25m), 1h 05m before it resets"), once a window. It reaches the phone too (as a finished turn's notification does: when you are away from the Mac).
- **A new branch from another one:** in Switch Branch, a typed new name offers **Create branch “…” from…**, then the branch it starts from (local or remote); the question before switching names it.
- **A picture pasted into the input editor** (Cmd+V with a screenshot on the clipboard) is kept as a file and its path goes in, for the command to take (`claude "look at <path>"`); pasted pictures go after a week. In a terminal where Claude Code runs, Cmd+V still gives it the picture itself.
- **A pane tab has a menu** (right click): Rename, Reload Claude Session, Split Right, Split Down and Close, as its row in the sidebar has (which offers the splits too).

### Fixed
- **A message sent while the Mac was away is no longer lost:** it was dropped while the chat said "Sent".
- **Claude Code's own steps read on the phone:** its plan shows as a document (approved or not), its question with your answer, its to-do list, and a slash command you ran with what it said; before, they were bare tool names or left out.
- **An old pairing code no longer unpairs a phone:** opening a used pairing link on a phone paired already connects it as before instead of failing.
- **Code in a numbered list on the phone** is no longer indented by the list.
- **Back closes a picture on the phone:** the back gesture (or button) closes an opened picture and leaves you where you were, as ✕ does; before, it went back behind it and the picture stayed.
- **Gemini CLI's sessions are Gemini's** on the Agents dashboard and the phone (they were taken for Claude Code's).
- **Tables on the phone read well:** a wide one (four columns or more) is a card a row, its cells under their column's name; a narrow one keeps its words whole and scrolls sideways when it must; two tables one after another stay two.
- **No tags in the phone's chat:** a background task's notice that reached Claude Code queued or in the middle of a turn showed as your message in raw `<task-notification>` tags; it is left out now.
- **A picture sent from the phone no longer hangs as "Sending":** Claude Code writes it as the picture, not its path; the message is matched by its place now.
- **No stray line in the phone's message box:** it was 2 px short and showed a scrollbar.
- **CPU cores on the phone in their level's colour** (green to red), on a track, as on the Mac.
- **Replies on the phone show as written:** `<br>`, `<details>` and `<https://…>` no longer show as tags; bold with code or a link inside, ~~struck~~ text, ``double-tick code``, plain links, `\|` in a table, `\*` escapes and `- [ ]` tasks are drawn as meant.
- **The phone's terminal keeps its history whole:** output that scrolls off while you watch it is there when you scroll up (before, only what was there when it opened).
- **"Since when" on the phone is right:** an agent's state showed "now" whatever its age.
- **Voice mode on the phone is clearer and steadier:** a panel above the keys shows what it does: listening, what it heard (sent after 5 seconds, with **Send**, **Edit** and **Cancel**, or say "send" or "cancel"), paused. When it hears nothing it listens again, and after a few tries it pauses and says so instead of stopping silently; recognition errors (no internet, the microphone busy) are said. Words ending in an accent, such as "zruš" or "prestaň", are understood as commands.
- **The phone's chat no longer jumps:** pulling it up while the agent writes keeps it under your finger, and typing a long message does not move it.

- **Groups and projects fold on the phone** as in the Mac's sidebar (a tap on a group's name or a project's arrow, kept on the phone), and **Files is by group** too.
- **The chat's details on the phone** say the model, how much of its context the session holds (with a bar) and its git branch.

### Fixed

- **The cup in the status bar opens its menu by the cup** also while Keep Mac Awake is off (it opened in the middle of the window).
- **A project's chevron in the sidebar stays where it is when its list opens** (open, it sat higher, on the name's line).
- **Not connected, the phone app says so plainly:** a loader over the page (blurred, nothing on it to tap: it may be old), then why when the Mac stays away (this phone offline; the Mac not reached, Tailscale off on the phone or the Mac asleep; Flashex not running on the Mac) with **Try again**. It connects again sooner while it is on screen.
- **A notification tapped opens its chat without "Your Mac cannot be reached".** A phone just woken takes a few seconds to reach its tailnet: what the app asks waits for it instead of failing, and the message comes only when the Mac stays away (10 s).
- **A new terminal on the phone shows its prompt at the top** instead of scrolling to the Mac's empty rows below it.
- **A terminal is no longer called "you@your-mac:~/path"** when the Mac's name changed since its shell started (on another network): it is named by its folder again, on the Mac and on the phone.
- **The phone's ⋯ sits level with Chat | Terminal.**

## [0.2.6] - 2026-10-21

### Added
- **More accent colours:** purple, pink, red, cyan and lime join orange, green, blue, indigo, teal and amber (Settings › Appearance › Accent).
- **Settings › Terminal › Remote terminals and projects over ssh** turns them on or off.
- **A remote terminal's tab shows its link.** A server icon in the pane's tab: green while connected, orange while it reconnects.
- **A host that cannot be reached again says why.** When a remote terminal's connection comes back failing (a login it needs, a host that is down), the terminal says why, once per reason, while Flashex keeps trying; when it needs a login, Log In to Remote Host… brings it back by itself.
- **Remote terminals left behind are cleaned up, and a gone one says why.** A remote terminal remembers which Flashex opened it: a while after the start, Flashex closes its own terminals on a host it no longer knows (left by a crash before the session was saved), never another Flashex's. A remote terminal that is gone says whether the host stopped it because no Flashex showed it within its grace period, or the host (or its server) restarted.
- **An icon for a project in the sidebar.** A project's menu › **Icon…** (or **Set Project Icon** in the command palette) shows it with an icon instead of its initials: code, docs, notes, images, design, web, data, AI, tools, cloud, music, games and more, so projects are easy to tell apart. A minimap and Settings by category, an Agents Timeline that shows who needs you, terminals that come back with what they showed after a restart, and a long round of fixes found by checking every screen by hand. macOS only; the Linux beta stays at 0.1.2 for now.

### Added
- **More settings in Settings (`Cmd+,`).** Editor › "Keep unsaved changes when quitting" (hot exit), Appearance › the window width under which a tab's panes show as a list, Terminal › memory for inline images and whether running agents and full-screen programs show as a plain terminal or as blocks. Each was only in `config.toml` before.
- **Pictures from files can be turned off.** Settings › Terminal › "Programs may show pictures from files" (`[terminal] image_files`, on by default) decides whether a program using the kitty graphics protocol may name a file on your Mac for Flashex to read and show; off, only pictures the program sends inline appear. It applies to new terminals.
- **Import a terminal color theme.** Settings › Appearance › "Import a terminal color theme" opens a file panel: pick a theme file (`key = value` lines such as `background = #1e1e2e` and `palette = 1=#f38ba8`, the format many terminal themes come in) and Flashex copies it into its themes folder and uses it right away. Terminal colors then shows "Custom". A file that sets no colour, is not text or is over 1 MB is refused with the reason.
- **Your own duration as Keep Mac Awake's default.** Settings › General › "Keep Mac Awake: default mode" now also offers **Custom**: the duration you typed last in the chooser (such as `1h30` or `until 18:30`) is then preselected, and `toggle_keep_mac_awake` starts it, reading it afresh each time (`[general] keep_awake_mode = "custom"`).
- **Keep Mac Awake after a restart.** When Flashex restarts (an update, Restart Flashex, a crash) while Keep Mac Awake is on, a notice offers **Keep Awake** to go on: a timed mode for the time it had left, "until I turn it off" and "while agents run" if Flashex was gone only a short while. It never turns on by itself.
- **Pull, Push and Sync from the Git menu and the command palette.** Git › Pull, Push and Sync (pull, then push) run in the active project's repository just as Source Control's buttons do, without opening the panel; in the palette they are "Git: Pull", "Git: Push" and "Git: Sync". **Go to Folder…** is now in the Terminal menu too. All four can get their own shortcut in `keybindings.toml` (`git_pull`, `git_push`, `git_sync`, `go_to_folder`).
- **Pictures' paths in the terminal preview on hover.** When Claude Code or any other program prints a picture's path (`Saved screenshot to ./shots/a.png`, `~/Desktop/x.jpg`, `` `chart.svg` ``, `![chart](out/c.png)`, `file:///…/a.webp`, `my\ shot.png`, or a macOS screenshot name with spaces), pointing at it underlines it once the file is found (relative paths are looked for in the terminal's folder, then the project's). Rest the pointer there for a moment and a small preview shows above or below it with the file's name, its size in pixels and on disk; it goes away when you move off, scroll or type. PNG, JPEG, GIF, WebP, BMP, TIFF, ICO and SVG are shown; files over 30 MB or pictures over 50 megapixels show only their details. `Cmd+click` opens the picture in the editor pane beside, and a right click offers **Open**, **Reveal in Finder**, **Copy Path** and **Copy Image**. In a program that uses the mouse, hold `Cmd`. The preview can be turned off in Settings › Terminal ("Preview pictures on hover") or with `[terminal] image_hover_preview = false`.
- **The Usage dashboard explains its terms.** Words with a dashed underline, such as pace, sustainable, the run-out forecast, the daily budget, median and p90, cache lifetime or where the limits come from, say what they mean when you point at them.
- **Agents Timeline: who needs you, at a glance.** Sessions waiting for you are always at the top, highlighted, with how long they have waited ("waiting 4 min · needs permission: Bash"); sessions at work follow, each with what it is doing right now ("Edit system_view.rs", "Bash: cargo test") and, when its transcript was read, its context ("84.0K · 42%"). Idle and ended sessions fold into one "▸ 5 finished" row with small strips of their activity, and a session's subagents fold into "▸ 3 subagents" under it; a click unfolds them, and a session that gets busy again moves back up by itself. A strip above the lanes counts sessions working, waiting and finished and sums how long agents waited on you today.
- **Agents Timeline: errors, details and the way back.** Failed tool calls and denied permissions show as red dots on their lane (read from the session's transcript). Pointing at a stretch or a mark shows a tooltip with what it was, the tool, how long it took and when; clicking a lane, a subagent's too, takes you to that session's terminal, bringing its project and tab to the front. Chips filter the timeline to one project, and the chosen window (15m / 1h / 4h), project and the finished fold are remembered across restarts.
- **`flashex keeper status`.** Lists the restart keepers that keep your terminals running across a crash or a restart, and what each holds: the app it belongs to, how many terminals it keeps and how many still run, and while it waits for the app to come back, how much output it has saved. It asks the keepers directly, so it works while Flashex is not running; `--json` gives the same as JSON.
- **Terminals come back with what they showed after a restart.** After "Restart Flashex" or an update, a terminal used to come back with only what its program printed while Flashex was away, and a blank screen above it. It now shows the lines it had (its screen and up to 500 lines of history, without colours), the cursor where it was, and then what came meanwhile. A full-screen program such as vim draws itself again as before.
- **Menus work from the keyboard.** The "+ ⌄" menu, the "»" list of tabs that have no room, the sidebar's right-click menu and the file tree's right-click menu now take ↑/↓ to choose a row and Enter or Space to run it, like the "?" menu; Esc or any other key closes them as before. In the file tree's question (Move to Trash, Discard Changes and the like), ←/→ or Tab put a focus ring on Cancel or the other button and Enter presses it; `Cmd+Enter` and Esc work as before, and a plain Enter with no button chosen still does nothing.
- **Popovers' buttons from the keyboard.** In the Claude Code restart popover (the refresh icon, Reload Claude Session) and the AI answer popover, ←/→ or Tab put a focus ring on a button and Enter or Space presses it; Esc closes them as before. Enter does nothing until a button is chosen, so a stray Enter never restarts a session.
- **Select text in the AI answer.** The Explain and Fix popover's answer can now be selected with the mouse (an I-beam over its text; drag across paragraphs, list items and table cells), `Cmd+A` selects the whole answer and `Cmd+C` copies the selection. Code blocks keep their own Copy button.
- **Only web servers next to a project, as a small globe chip.** The sidebar no longer shows every port a project's programs listen on (a bare `:50213` was often an agent's IDE bridge, a debugger or Node's inspector). Flashex asks each new port once, with a short HTTP request on a background thread, and shows only the ones that answer like a web server. They appear as a quiet chip with a globe and the port that brightens when you point at it; its tooltip says what a click does and which program serves it ("Open localhost:5173 in a browser panel — served by node"). With several servers the chip shows the first and "+2", which lists the others and lets you choose one. In a narrow sidebar the chip is just the globe. **Open Port in Browser…** in the command palette lists the same servers.
- **Reload Claude Session asks next to its terminal.** When Claude Code is busy and Reload Claude Session comes from the command palette or its shortcut, the question now opens under that terminal's pane tab instead of at the top of the window (it stays at the top when the tab is not on screen).
- **Panes reach the bottom of the window.** The panes used to end a few pixels above the status bar, short of the sidebar's foot, whenever the window's height was not a whole number of text lines; the same sliver was left at the right edge. Panes on the bottom and right edges now take that room, so they line up with the sidebar.
- **Explain, Fix and Send to hide secrets in the output too.** A command's output sent to an agent or an AI provider now has passwords, tokens and keys replaced with `***`, as its command line already had (`TOKEN=…`, `--password …`, `user:password@` in URLs, well-known API tokens and long random strings). Commit ids and checksums stay readable.
- **A block's bar in a narrow pane keeps Fix.** When a failed command's bar has no room for everything, the agent's chip ("Claude 2") now goes before a tool does, so you get "Explain" and "Fix" side by side instead of "Explain · Claude 2" with Fix hidden in "⋯". The tooltip still says where each one goes.
- **"Send to…" tells agents in one tab apart.** With two agents in split panes of the same tab, the list named both "Claude (tab 2)"; the second is now "Claude (tab 2) · 2".
- **Failed tools reach the Agents Timeline at once.** Flashex's Claude Code hooks now also listen for a failed tool call, so its red dot appears the moment it fails (with the command or file it was about) instead of after the transcript is read. The hooks update themselves when Flashex starts if your Claude Code is 2.1.119 or newer (otherwise Settings › AI agents offers the update); a failure reported by both the hook and the transcript is one dot, which turns into "Permission denied" when the transcript says so.
- **Language, indentation and line endings from the status bar.** With an editor focused, click its language to pick another one for its colours (or Auto Detect, or Plain Text); click the indentation to choose what Tab inserts (2, 4 or 8 spaces, or a tab) or to convert every line's leading indentation to spaces or tabs; click LF or CRLF to change the line endings the file is saved with. Converting and changing line endings are one step each to undo.
- **HEIC pictures.** iPhone photos and other HEIC / HEIF pictures (`.heic`, `.heif`, or told by their contents) now open in an image tab with their size, preview on hover when a terminal prints their path, and can be copied with **Copy Image**; macOS decodes them.
- **Terminal rows in the sidebar: a menu and dragging.** Right-click a terminal's row under a project for **Rename** (give the terminal a name of its own; an empty name gives it back to its program) and **Close**, also from the keyboard like the sidebar's other menus. A row of the tab on screen can be dragged into a pane or its tab strip, as its pane tab can.
- **Close and reorder panes in a tab shown as a list.** Each row of the list has a × (shown on the selected row and on hover, a dot while a file in it is unsaved) that closes that pane with its tabs, asking first when something still runs; drag a row before or after another to change its place.
- **Pick a custom project colour with the mouse.** "Custom…" in a project's or group's colours now shows a colour square and a hue bar under the hex field; click or drag in them and the field and the swatch follow. Typing a hex value works as before.
- **Settings by category.** A bar at the top of Settings (`Cmd+,`) jumps to Appearance, Terminal, Editor, AI, Browser or General, and marks the category you are reading as you scroll; `Cmd+]` and `Cmd+[` go to the next and the previous one. In a narrow window the bar shows only its icons (the name in a tooltip). The sections are grouped under them: Language Servers and Source Control under Editor, AI agents with AI, and Keyboard, Notifications, Session and Updates under General.
- **A minimap in the code editor.** An editor pane wide enough for a hundred columns of text beside it shows the file drawn small on its right edge, in its syntax colours, with the part on screen as a light slider. Click it to jump there, drag the slider to scroll; the mouse wheel scrolls as over the text. It hides in a narrower pane and is not shown in a diff. Settings › Editor › "Minimap (wide panes)" or `[editor] minimap = false` turns it off.

### Changed
- **The branch line in the sidebar uses the whole row.** The chevron that folds a project's list of terminals no longer keeps an empty space at the end of the project's row; it appears over the row's end while you point at the row. A long branch name is now cut much later, and the counts and the web server chip stay whole as before. A folded list still shows its chevron all the time.
- **Line numbers sit in the middle of the editor's gutter**, as in Sublime Text, instead of against its right side; the current line's number is still brighter, and error dots and change marks stay at the gutter's edges.
- **Keep Mac Awake is set where you turn it on.** Settings no longer has a General section with Keep Mac Awake's rows. Its chooser (Cmd+K › Keep Mac Awake…) remembers what you pick there: the mode you start becomes the one preselected next time ("last used") and the one `toggle_keep_mac_awake` starts, and the Display and Screen lock toggles under its rows are kept for the next time too. They are stored in the same `[general]` keys as before (`keep_awake_mode`, `keep_awake_display`, `keep_awake_lock`), so an existing `config.toml` keeps working.
- **The browser panel's bar stands apart from the page.** The bar with the back, forward and reload buttons and the address now sits on the same grey as the pane's tabs, with a thin line above the page, and the address field has the page's colour; in the light theme a white page no longer blends into the bar. It follows the light and dark themes.
- **macOS remembers Flashex's permissions across updates.** Flashex is now signed with its own certificate instead of a new ad-hoc signature for every version, so permissions such as Accessibility stay granted after an update. After updating to this version, grant them once more (System Settings › Privacy & Security); later updates keep them.
- **SSD and battery temperatures get bars too.** In the System dashboard's Temperatures card, the SSD and the battery now have a row with a coloured bar each, like the CPU and GPU, instead of sharing the "also" line. Each bar has its own range (SSD 30–80 °C, battery 25–50 °C), so its colour says how close that part is to too hot: a battery at 45 °C now reads amber, not a short green bar on the chip's scale. A group with a single sensor shows its reading once.
- **The System dashboard reads as one board.** The machine is no longer a card near the bottom: a one-line strip above the cards says chip, macOS, cores, load, uptime and battery, and its chevron opens the full details (remembered, `[dashboards] system_details`). Every card's chart now sits at its foot with the same height, so the charts of cards side by side line up.
- **A shorter Processes card.** When there is no room for the two tables side by side, the card shows one at a time with **CPU** and **Memory** chips above it instead of stacking them; the choice is remembered (`[dashboards] system_processes`).
- **Terms in the System dashboard explain themselves.** Labels with a dashed underline, such as load, P + E cores, pressure, swap, the temperature groups or the network rate, show a short explanation when you rest the pointer on them.
- **Agents are named by you or by what they are, not by the title they set.** In the sidebar and in the Agents dashboard, an agent's terminal is now called by the name you gave it, else by the agent ("Claude Code"), as notifications already did, instead of whatever title the program set (which could read "Flashex: your session expired…"). Two agents in one project are told apart as "Claude Code" and "Claude Code · 2", in the dashboard too.
- **The Usage dashboard holds far less memory.** Requests older than a day are kept as small summaries (they still count in the totals and in pricing subagents' output), so a busy week of Claude Code now takes under 3 MB instead of tens of megabytes. The first open after this update reads the transcripts again once.
- **Softer folders and lists.** A folder opened in the file tree fades its rows in, switching between Files and Source Control fades the new view in, and a project's list of terminals in the sidebar fades in as you unfold it. With Reduce Motion or animations off they appear at once.
- **Pane strip and block buttons match the rest.** The zoom button, the "Zoomed" chip, Open Preview / Edit and the tools on a command block's bar are now the app's small quiet buttons, with the same padding, hover and pressed look as the buttons in bars and notices.
- **SVG pictures from the terminal open as pictures.** `Cmd+click` or **Open** on an SVG's path in a terminal now shows the picture in an image tab, with its size, instead of its text; the file tree and `Cmd+P` still open SVG files as text to edit.
- **The window opens where you left it, even without session restore.** Its size, place and display are now remembered with `[session] restore = false` too (before, the window then always opened centred at 1200 × 760). A window whose display is gone opens on the main one, moved and shrunk to fit.
- **Programs can no longer change a terminal's width.** A program that switches to 80 or 132 columns (DECCOLM, as vttest and some old tools do) now only gets a cleared screen with the cursor at the top left; the terminal keeps the width of its pane.
- **Pane sizes keep their proportions on another display.** Dragging a divider (or growing a pane from the keyboard) now remembers the split as a ratio instead of a fixed number of columns, so a layout set up on a wide monitor looks the same on a laptop: the panes shrink together rather than the left one keeping its width and squeezing the rest. Panes still never go below their minimum size, and a size you set with the `size` command stays as you set it. A split dragged in an earlier version keeps its fixed width until you drag that divider once more.

### Fixed
- **File › Open File… opens several files.** The menu bar's Open File… let you pick only one file, while the one in the "+" menu took several; both now open every file you select.
- **Sidebar tooltips follow the rows.** After scrolling the sidebar with the wheel, the tooltip of the row that had been under the pointer stayed, and a terminal's "Claude: waiting" tooltip stayed after the agent went idle, until the mouse moved; both now go.
- **A notice with a button uses the whole card for its text.** The button (such as "Update Claude Code hooks…") sat beside the text and squeezed it into a narrow column; it now sits under the text, at the right.
- **No trust question for a language server that is not installed.** A file outside your projects asked "Start language server for …?" even when the configured server program did not exist, and Trust started nothing; the editor now shows the server as not installed instead.
- **Show Diff says when git was only slow.** When git took too long to give a file's committed version, `Ctrl+Shift+G` said "This file has no version in git HEAD."; it now says git did not answer in time and asks again, so the diff opens on the next try.
- **A layout template's `60c` gives the terminal 60 columns.** Pinned sizes in templates were the layout's cells, so `60c` gave a terminal of about 57 columns; they now count the terminal's own columns and rows, as `flashex size` does, and Save Layout as Template… writes them back the same way, so a template no longer grows each time it is saved again.
- **An editor whose file was missing opens it once it is back.** A tab restored while its file was not on disk (another branch checked out) said "Cannot open … No such file" until it was closed and opened again; it now opens the file as soon as it returns.
- **Notices about unsaved texts and Claude Code hooks read right.** One unsaved text moved aside at start is now "1 unsaved text … was moved", not "1 unsaved texts … were moved", and a Claude Code hooks file that could not be updated no longer says "nothing was changed" twice.
- **Keyboard Shortcuts and Workflows fit a narrow window.** In a window under about 700 pt their cards kept their full width and ran off the left edge; they now narrow with the window like the palette and Settings.
- **Workflows… is no longer cut by a browser panel.** The page of a browser panel under the Workflows list or the Save as Workflow card was drawn over them; it now hides while they are open, as under the palette and Settings.
- **Switching branches mentions unsaved editors in a linked folder.** The question before a branch switch says when files of the repository have unsaved edits in an editor; for a repository reached through a link (such as anything under `/tmp`) those editors were not counted and the question left them out.
- **Saved layout templates load again.** Save Layout as Template… could write a size of `0c` for a pane, and then every template in `layouts.toml` was refused with "bad size". Such a size is now saved as the default share.
- **No pane is pinned at nothing.** Splitting a pane whose width or height had been set to a single cell (by halving a `size` again and again) pinned the new half at no cells at all, which is where the `0c` in a saved template came from; the new pane now shares the room that is left.
- **`size 60` gives a terminal 60 columns.** The `size` command (`flashex size`, the palette's "size …") counted the pane's padding in, so `size 60` left 57 or 58 columns; a size in cells is now the terminal's own columns or rows, whatever the font, when the window has room.
- **A page that does not load says so.** In a browser panel, an address that could not be loaded (nothing listening, connection refused) emptied the address field and left a white page with no word, on a new panel as well as over a page that had loaded. The address you typed now stays in the field and the line under the bar says it could not be loaded; Reload tries it again.
- **A split starts where the shell is after `exec sh`.** After `exec sh` (or another shell that does not report its folder) and a `cd`, the first `Cmd+D` could open in the folder the previous shell had reported; a split now asks where the terminal is at that moment.
- **Every file in the sidebar names its path.** After a restart, a file in a tab you had not opened yet showed no tooltip in the sidebar's list under its project; it now names the file's path as soon as the app starts, as a loaded file's row does.
- **The active tab's close button stays whole in a crowded pane.** In a narrow pane with "» N" (a Markdown file with its preview button, for instance), the pane's drag handle kept its place even after the layout had given its room to the tabs, so the active tab was cut and its close button showed only in half. The handle now gives way first, as intended.
- **The System dashboard's machine strip in a narrow pane.** When the strip wraps, a line no longer starts with "·": each dot stays with the fact before it.
- **Commenting Markdown lines that end with an empty line.** `Cmd+/` on a selection whose last line was empty put `-->` on that empty line; the comment now ends after the last line with text.
- **Web servers behind an ssh tunnel show next to the project.** A port forwarded with `ssh -L 8080:localhost:80 server` (or `ssh -N -L …`) is now asked like any other, through the tunnel, and appears as the globe chip when a web server answers at the other end; its tooltip says "served by ssh (tunnel)". Only the ports ssh listens on here are asked; the ssh server (`sshd`) is still left alone.
- **The System dashboard in a narrow pane.** Process and interface names no longer shrink to a bare "…": the number columns give way first, down to what their figures need. "2.9 GB of 4.0 GB" (memory, swap, disk) and the load averages wrap onto the next line instead of running past the card's edge, and a chart's time axis reads round values ("-5m", "-2m 30s") instead of "-5m 4s".
- **Ctrl+Tab at the prompt types nothing.** In a pane with a single tab, Ctrl+Tab at the shell's prompt left `;5;9~` in the command line; with nowhere to go it now does nothing there, while a running program (a TUI that uses it) still gets the key.
- **A shell that exits ends its last command.** After `exit` or `logout` the `exit` block kept running: its time went on growing, and the tab and the status bar still showed "exit" as the running command. The block now ends with the shell, with its exit code.
- **Hot exit turned off keeps no old text.** With `hot_exit = false`, quitting without saving brought an Untitled's text back at the next start from a backup made while hot exit was on. Quitting now drops every backup (it asks first when one would hold text), and the session names none.
- **A restored empty Untitled has no unsaved dot.** An empty Untitled brought back after a restart showed the unsaved-changes dot on its tab until it was opened; only one with text kept from before shows it now.
- **Typing an action in the branch picker picks the action.** Typing "Fetch" put "Create branch “Fetch”" first, so Enter made a branch named Fetch; an action whose name you type now comes before the Create row.
- **Claude Code hooks upgrade once the version is known.** When the installed `claude` is a wrapper whose files do not tell its version, the automatic upgrade of older Flashex hooks waited for the next start; it now runs as soon as `claude --version` tells a version that supports them.
- **Terminals come back with their prompt after a crash.** When Flashex was force-quit or crashed and you opened it again, the terminals it reconnected ("Reconnected 3 terminals") stayed blank until you pressed Enter. Each one now gets a brief size nudge that makes the shell draw its prompt again, and full-screen programs such as vim or htop repaint themselves.
- **A click in the AI answer clears its selection.** In the Explain and Fix popover, a click beside the answer's text (its margin, the title or around the buttons) left the dragged selection in place; it now clears it, as a click on the text already did.
- **Pictures inside a line of Markdown are drawn.** The Markdown preview drew a picture only when it was alone in its paragraph; one inside text, such as `Relative: ![shot](shots/a.png)` or a linked badge `[![build](badge.png)](…)`, showed only its alt text. Pictures from your Mac now appear right under the paragraph they are in (as wide as the column at most); web pictures inside text stay their alt text.
- **Quoted secrets stay out of Explain and Fix.** A secret assigned inside quotes in the command itself, such as `echo "TOKEN=…"` or `sh -c 'API_KEY=… make'`, was sent to the AI provider as it was; its value is now hidden like any other (`TOKEN=***`), and only the value, not the closing quote after it.
- **No blank frame after a long scroll.** Flicking the System dashboard, the file tree or Source Control far past its end with the trackpad or the wheel could leave the panel empty for a moment before the cards or rows came back; they are now there in the same frame.
- **Agents › Sessions keeps the terminal's name in sight.** A session in a folder outside your home showed the whole path on its second line and "· Claude Code" fell off the end; a long folder now gives way from the left ("…/gui-g1/web · Claude Code") so the terminal's name always shows.
- **Settings rows light up under the pointer**, so you can see which row a click will change. The Claude Code hooks row also checks the hooks again when you click it or come back to Flashex, instead of only when Settings opened.
- **Cmd+V pastes a screenshot into Claude Code.** With only an image on the clipboard (a screenshot copied with Cmd+Ctrl+Shift+4, an image copied in Preview or a browser), Cmd+V used to do nothing at all. Now a program that takes pastes, such as Claude Code, gets an empty paste, and Claude Code attaches the clipboard's image just as it does on Ctrl+V. At the shell's prompt or in a program that cannot take an image nothing is typed; a short notice says to paste it into an agent with Ctrl+V instead. Ctrl+V always goes to the program, and pasting text is unchanged.
- **The Usage dashboard's header in a narrow pane.** Its buttons no longer drop to a half-empty row of their own: they first show just their icons (the tooltip names them), and in a very narrow pane the 1h…24h choice moves under the title instead.
- **Tidier numbers in a narrow Usage dashboard.** The Today card shows its numbers as tiles in even columns (six, three or two a row as the room allows) instead of a line that wrapped raggedly, and the Throughput card's cache numbers wrap under the first number, not back under the "Cache" label.
- **The update card is never hidden behind a browser panel.** A browser panel reaching into the window's bottom-right corner used to cover the card offering an update; its page now steps aside until the card is answered.
- **Terminals in hidden tabs keep their width after a restart.** A terminal taken back after a crash, an update or "Restart Flashex" in a tab you had not opened yet was squeezed to 80 × 24 until you looked at it, so programs such as Claude Code redrew narrow and then again; it now keeps its size until it is shown.
- **A program that ended during a restart still shows what it printed.** When a terminal's program finished while Flashex was restarting or after a crash, its pane used to come back with a new shell and nothing of the output; it now shows the program's last output followed by "[process exited]".
- **New Claude Code starts the `claude` your shell would.** The "+" menu's New Claude Code looked for `claude` on the app's own PATH, which can differ from your login shell's (an app opened from the Dock), and could start another copy than the one your terminals run; it now looks on your login shell's PATH first.
- **The restart keeper comes back if it stops.** If the small helper that keeps your terminals across a crash or a restart was killed or crashed while Flashex ran, your terminals kept working but would no longer survive a crash of the app; Flashex now starts a new keeper at once and hands it every open terminal.
- **An update that crashes at start rolls back by itself.** If the new version starts but quits or crashes before it is up (within a minute), Flashex puts the previous version back, starts it and says the update did not go in, instead of leaving you with an app that will not open.
- **The System dashboard in a narrow pane.** Its header no longer wraps Public IP and Help to a half-empty row: they show just their icons first, and in a very narrow pane the machine's facts move under the title. The cards' number lines wrap between whole pairs ("free 9.9 GB" never splits), each new line starting under the first value, not under the label.
- **`CLAUDE_CONFIG_DIR` from your shell is honoured when Flashex starts from the Dock.** Flashex now reads it from your login shell and your `.zshrc`, as it does for PATH, so the Usage dashboard and the Claude Code hooks use the folder Claude Code really uses instead of `~/.claude`.
- **Accented letters in the Agents filter.** Typing in the Agents dashboard's filter now goes through the keyboard's input method, so dead keys (ˇ then c gives č) and other input methods work there as they do in the terminal.
- **The Agents dashboard reopens on the tab you chose.** Sessions or Timeline is now remembered across restarts, like the Timeline's window and project.
- **The Timeline's "Thinking" after a failed tool.** Pointing at the stretch right after a red dot said "Thinking" with the failed tool's command; it now says just "Thinking", and the dot keeps the command.
- **The new-version icon knows which Claude Code a session runs.** A session that was already running when Flashex started, or that Claude Code was updated under before Flashex saw it, was taken to run the version installed at that moment, so its update could go unnoticed. Flashex now reads the version from the session's transcript.
- **Notifications say which program they are about.** A program's own notification without a title (OSC 9) is now titled with the program that sent it instead of "Flashex", and "Command finished" names the terminal by the command that ran ("api · make") instead of its folder.
- **Readable counts in the clipboard notice.** "Claude Code copied 1,266 characters to the clipboard" now groups the thousands.

It also works with the prompt editor turned off, unless your shell suggests on its own (zsh-autosuggestions, fish). `[ai] ghost_text = false` turns it off.
- **Claude Code updates while you work.** When a newer Claude Code is installed while a session runs in a terminal, a refresh icon appears after that terminal's tab title and in the sidebar. Click it to restart the session on the new version; the conversation continues, with the options you started it with. If Claude Code is busy, choose **Restart when idle** and it restarts on its own once the task is done. The palette's "Restart Idle Claude Sessions on the New Version" does it for all idle sessions, and Settings › AI agents turns the icon off. The hook this needs is added on its own when Flashex starts (see Changed).

### Changed
- **Claude Code hooks update themselves.** When Flashex's Claude Code hooks are installed but come from an older Flashex, the app updates them in place at start and says so once; Claude sessions already running pick them up on their next start. Only commands exactly as Flashex wrote them are touched (your other hooks, even ones that mention Flashex, your keys and formatting stay; a read-only file is left alone), backups are kept as `settings.json.flashex-backup` and, the first time, `settings.json.flashex-backup.orig`, and nothing is installed unless you ask. Settings › AI agents shows whether the hooks are installed, outdated, incomplete or customised, with an Install / Update button that asks before it writes, and `flashex setup claude` can be run again safely.
- **Progress notices turn into their result.** "Looking for updates…", "Fetching…" and similar notices now stay until the work is done and are then replaced in place by the result or the error, with a short crossfade, instead of a second notice stacking above them. When a new version is found, the update card takes the place of "Looking for updates…". Results of repeated git operations, Claude Code restart notices and clipboard notices also replace each other.

### Fixed
- **Settings rows fit the sheet.** A long value no longer runs past the right edge or into its label. Values end in "…" between their arrows when there is no room, labels wrap to two lines, and hovering a shortened row shows it in full. The prompt setting now reads simply **Auto**, with a short explanation under its name.
- **Check for Updates no longer leaves "Looking for updates…" on screen** next to the answer, and asking twice shows it once. Asking while the daily check is already running now answers too, instead of doing nothing.
- **The settings list follows the arrow keys.** With ↑/↓ or Tab, the list scrolls to keep the selected row in view, with a short glide. The glide is skipped when animations are off or Reduce Motion is on.

## [0.1.0] - 2026-10-08

The first public release, for Apple Silicon Macs with macOS 13 or later.

### Added

**Terminal**
- `flashex-vt`, Flashex's own terminal core written in Rust. It passes 450 of 567 esctest2 tests, and has run for hours of fuzzing without a failure.
- Inline images: the kitty graphics protocol, sixel and iTerm2 images, which scroll with the text.
- The kitty keyboard protocol, SGR-pixel mouse reports, XTGETTCAP and the window-title stack.
- Command blocks: each command shows with its folder, duration and exit code. You can jump between blocks, select, fold, copy or rerun a block, or save it as a workflow.
- Shell integration for zsh, bash and fish, set up automatically. Its marks are signed so programs can't fake them.
- A compact prompt with a clickable path. Click the path to open the folder or to switch to a nearby one.
- Find in the terminal, including the scrollback.
- Splits, zoom, tabs inside a pane, layout presets and a quick layout switcher. New splits start in the focused terminal's folder.

**AI agents**
- Claude Code hooks (`flashex setup claude`) report when an agent is running, waiting for you or done.
- The sidebar shows each agent's state as a dot. Notifications point at the exact terminal, and the notification center lists what happened.
- A finished Claude Code session can be resumed from its command block.

**Editor**
- Tree-sitter highlighting.
- Multi-cursor editing in the style of Sublime Text and VS Code.
- Language-server features from the servers you have installed: go to definition, references, hover, completion, rename and diagnostics.
- Markdown preview.
- Hot exit: unsaved and untitled files survive a quit, a crash or a restart.

**Projects and Source Control**
- Projects and groups in the sidebar, with the branch and git state shown as `↑` ahead, `↓` behind and `±` changed files. Hover the marks to see what they mean.
- Source Control: stage, unstage, discard, commit, pull, push and switch branches, with side-by-side diffs against HEAD.
- A file tree, a palette (`⌘K`) and a keyboard shortcuts sheet (`⌘?`). Shortcut labels follow your keyboard layout.
- A browser panel for local pages.

**App**
- A restart keeper. A tiny helper process holds your terminals while Flashex restarts after an update or a crash, so shells, agents and running jobs carry on. Quitting with `⌘Q` still ends everything, and the keeper stops on its own after a grace period.
- In-app updates. Flashex checks for a new version at start and once a day, and shows a quiet card in the corner of the window. Nothing is installed until you click Update and then Restart Now. Updates are signed with Flashex's own key and checked before they are installed. You can also check by hand from the `?` menu, the app menu or the palette.
- Animations for splits, zoom, tabs, the sidebar and popups. Turn them off in Settings; they also follow macOS Reduce motion.
- Light and dark themes with a choice of accent colour.
