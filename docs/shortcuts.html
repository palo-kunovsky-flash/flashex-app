Keyboard shortcuts

The default shortcuts, the key profiles, and how to change any of them. In the app, ⌘? lists every shortcut in effect and filters them as you type.

Key profiles

[keys] profile picks a set of conventions: "flashex" (the default), "sublime" or "vscode". The defaults already follow Sublime Text and VS Code for most editing keys; a profile changes only the few that differ. keybindings.toml applies on top of the profile.

keybindings.toml

Flashex reads ~/.config/flashex/keybindings.toml next to config.toml. Changes apply immediately. A line that is wrong (an unknown action, a keystroke Flashex cannot use, the same keys twice) is reported with its line number and left out; the rest applies.

~/.config/flashex/keybindings.toml
# Add a shortcut (the action keeps its default one).
"cmd-shift-y" = "new_tab"
# Remove a shortcut.
"cmd-d" = "none"
# Give a key another action (its old action loses this key).
"cmd-t" = "split_right"

[editor]      # while a code editor has focus; wins over the global ones there
"cmd-alt-w" = "toggle_wrap"

[browser]     # while a browser panel has focus
"cmd-shift-r" = "browser_reload"

Keystrokes: modifiers cmd, ctrl, alt (option), shift, fn, then one key: a character, enter, escape, tab, space, backspace, delete, insert, home, end, pageup, pagedown, up, down, left, right or f1…f24. The - key is written cmd--. Shifted punctuation is written as the character it types (cmd-{). The order and case of the modifiers do not matter.

  • Global and browser shortcuts need cmd or ctrl (or a function key), so they never take away typing. Outside the editor, ctrl without cmd may not go with a letter or [ \ ] ^ _ / @ or space: those are control characters the shell needs (^C, ^R, ^D).
  • In [editor], alt alone only goes with a named key or a function key (alt-left, alt-f5), since Option with a character types @ [ ] { } on many layouts.
  • "none" removes any shortcut. Sequences of keystrokes (cmd-k cmd-i) are not supported.

Shortcuts follow your keyboard layout: a shortcut written with a character fires on the key that types that character, and the labels in the app show your layout's keys. The names of all actions are in the last table.

Other keys

  • File tree (⌘0 gives it the keyboard): ↑ ↓ move, → opens a folder, ← closes it, Return opens a file, Esc gives the keyboard back.
  • Source Control: ⌘↩ commits from the message field. Before moving something to the Trash or discarding a change, ⌘↩ confirms and Esc cancels.
  • Closing: a question about running programs or unsaved files closes with ⌘↩ and cancels with Esc.
  • Menus and popovers: ↑ ↓ (or ← →, Tab for buttons) choose, Return or Space runs, Esc closes.
  • Settings: ⌘] and ⌘[ go to the next and previous category.
