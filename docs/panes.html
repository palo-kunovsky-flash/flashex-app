Panes, tabs and layouts

Each project has tabs in the top row; each tab is a layout of panes; each pane can hold several tabs of its own.

Tabs

  • Project tabs are in the top row. ⌘T opens one, ⇧⌘W closes it (asking first when something still runs or is unsaved), ⌘1 … ⌘8 go to a tab, ⌘9 to the last one, and ⌘} / ⌘{ to the next and previous. The tabs that have no room are listed under ».
  • Pane tabs are in each pane's own strip. ⌥⌘T opens a terminal tab in the focused pane, ⌃Tab goes to its next tab, and the + / ⌄ buttons open terminals, files, a browser or Claude Code there. ⌘W closes the focused pane tab, and the pane with its last tab.

A tab's title follows what runs in it ("api — make"); give a terminal a name of its own with Rename in its sidebar row's right-click menu.

Splits

Focus the pane in a direction⌥⌘← ⌥⌘→ ⌥⌘↑ ⌥⌘↓
Focus the next / previous pane, in reading order⌃⌥Tab ⌃⌥⇧Tab
Back to the last focused pane⌘;
Move the pane: swap it with its neighbour⌥⇧⌘← ⌥⇧⌘→ ⌥⇧⌘↑ ⌥⇧⌘↓
Grow the pane on that side⌃⌘← ⌃⌘→ ⌃⌘↑ ⌃⌘↓

Zoom the pane (and back)⇧⌘↩
Show the tab's panes as a list⌥⌘L

Drag a divider to resize; a double click on a divider equalizes the split. A dragged size is kept as a ratio, so a layout made on a wide monitor looks the same on a laptop. In a code editor ⌘D and ⇧⌘D are editing keys instead (see Keyboard shortcuts).

⌃⌥Tab goes round the panes of the tab, left to right and top to bottom, and back to the first after the last (⌃Tab alone goes round the tabs inside a pane). Moving a pane swaps it with the pane on that side: the two trade places, each place keeps its size, and the focus stays with the pane you moved. Both do nothing while a pane is zoomed; in a list they follow the list. The menu has them under Window, the command palette finds them as switch pane or move pane.

Exact sizes

Type size 60% or size 80 (columns) into the command palette, or run flashex size: N columns or rows, or N% of the split; cols or rows picks the direction. A pinned size stays when the window is resized, until you drag that divider or equalize.

Panes as a list

Show Panes as List (⌥⌘L) shows one pane of the tab at a time with a list of the others, keeping the layout for later: useful on a small screen. Each row has a × to close that pane, and rows can be dragged to reorder them. [layout] auto_stack_below does it automatically below a window width.

Dragging panes

Grab a pane by one of its tabs, or by the free part of its tab strip (or the grip after +⌄) to take the whole pane with all its tabs, and drop it:

  • in the middle of another pane: it becomes a tab there;
  • near an edge: it splits that side;
  • in a pane's tab strip: it goes exactly where the marker shows;
  • on the free part of the top tab bar: it becomes a tab of its own.

A highlighted preview shows where it lands; Esc cancels. Terminals keep running. The palette's Merge Pane into Tabs, Join All Panes as Tabs, Move Pane to New Tab and Merge Tab into Current do the same from the keyboard. A terminal's row in the sidebar can be dragged into a pane too.

Layouts and templates

The palette has ready layouts for the current tab: Layout: 2 Columns, 3 Columns, 2 Rows, 2×2 Grid and Main + Side. Save Layout as Template… keeps the current one in ~/.config/flashex/layouts.toml, and Apply Layout Template… applies one. The file is plain text you can edit:

~/.config/flashex/layouts.toml
[[layout]]
name = "dev"
tree = "cols(60c pane, rows(pane, 30% pane))"

cols(…) puts its children side by side, rows(…) stacks them, and pane is a slot. A child may start with its size: a weight (2; the default is 1), cells (60c: the terminal's own columns or rows) or a share of the split (30%).

Closing and reopening

Closing asks first when something still runs or is unsaved. ⇧⌘T brings back the last closed project, tab or pane tab, and Reopen Closed… in the palette lists them. The whole session (groups, projects, tabs, splits, editors) is restored at the next start ([session] restore), and a restored terminal offers to run again the command that was running in it, never by itself (offer_rerun).

Font size and weight

⌘= and ⌘- make the focused pane's text bigger or smaller, a point at a time, as a browser zooms one tab: a terminal gets the columns and rows of its new size (its program sees the resize, as when the pane is dragged), an editor its lines, a dashboard its text, rows and charts, 10 % at a time. A notice says what changed and where (This pane: 16 pt (+2), Dashboard text 120%). The pane keeps its size across restarts, a split of it starts at the same size, and ⌃⌘0 puts it back. With ⌃⌥⌘=, ⌃⌥⌘- and ⌃⌥⌘0 the same goes for every terminal and editor, for good: the font size in Settings › Text is written to config.toml (zoomed panes keep their steps from it), and Reset puts it back to 13 pt and clears every pane's own size. Settings › Text also sets the size of the interface's text and the file tree's. ⌥⌘= and ⌥⌘- step the weight of every pane. In a browser panel the page gets ⌘= and ⌘-. ⌃⌘F toggles full screen. Animations for splits, zoom, tabs and popups follow the display's frame rate and turn off with macOS Reduce motion or animations = false.
